Project Overview:
This project focuses on analyzing an E-commerce dataset to track sales performance, customer behavior, and inventory health. As a Business Analyst, I built this end-to-end solution to transform raw transactional data into actionable business insights using SQL for data extraction and Power BI for advanced visualization.

🛠️ Technical Stack:
Data Cleaning & Transformation: Power Query (M Language)

Data Modeling: Star Schema (Fact and Dimension tables)

Analysis: SQL (Joins, CTEs, and Aggregations)

Visualization: Power BI (DAX measures like Year-over-Year growth, Total Revenue, and Profit Margin)

📊 Key Business Insights:
Sales Trends: Identified peak sales periods and seasonal fluctuations to optimize marketing spend.

Category Performance: Analyzed top-performing product categories to assist in inventory restocking decisions.

Customer Segmentation: Visualized high-value customer segments to improve retention strategies.
